Get started

Deploy in 5 minutes.

You need Docker with the Compose plugin. Nothing else.

  1. Download two files The compose file and the environment template.
  2. Set two values Replace APP_API_KEY and POSTGRES_PASSWORD in .env.
  3. Start it The database schema is created on first start.
  4. Point your editor at it Set api_url and api_key in ~/.wakatime.cfg, then open the dashboard on port 8080.
shell 
mkdir waka-personal && cd waka-personal
curl -fsSLO https://raw.githubusercontent.com/dvgamerr-app/waka-personal/main/docker-compose.yml
curl -fsSL https://raw.githubusercontent.com/dvgamerr-app/waka-personal/main/.env.example -o .env
# edit APP_API_KEY and POSTGRES_PASSWORD in .env
docker compose up -d
~/.wakatime.cfg 
[settings]
api_url = http://YOUR_HOST:8080/api/v1
api_key = REPLACE_ME

HTTPS, backups, upgrades and importing old data are covered in the self-hosting guide.

Use it

It speaks WakaTime.

Plugins just work. You can also call the API directly; the key goes in as the Basic-auth username, exactly like the plugins send it.

shell 
curl -u "REPLACE_ME:" http://YOUR_HOST:8080/api/v1/users/current/statusbar/today
